# 代码发布与个人知识分离

这个仓库是可复用的运行系统，不是作者个人知识库的公开镜像。

公开材料包含自有运行代码、网页、测试、协议、评价方法、可选宿主安装器及人工编写的演示数据。不会把使用者的技能目录全文、原始 JSONL、实际项目源码、个人经验底账、凭据、宿主配置备份或验收会话上传到代码仓库。

`bootstrap.py` 生成的演示库用于快速理解。真实使用时可继续受控写回，或按 importing.md 在新目录建立自己的库。`data/`、`reports/`、`integrations/` 与本地导出默认由 `.gitignore` 排除。不要用 `git add -f` 上传这些本地材料。

运行时 `export` 是私人迁移功能：它会包含图谱、账本和派生底账，可能含私人项目摘要与本机路径。它不复制原始日志，并不代表产物适合公开发布。分享前应单独核对内容，不直接把私人 export 附到 GitHub Release。

首次发布从独立目录建立新 Git 历史，没有带入使用者的旧仓库历史。安装器写入的备份与报告不属于发布代码。移动库后核对根路径与证据引用；路径存在和哈希一致仍不能替代对结论的审查。
